= UC-14: Stop activity — organizer ends it for everyone
:icons: font

[cols="1,3"]
|===
| ID | UC-14
| Path type | Positive
| Feature | xref:../features.adoc#_feature_3_organise_an_activity[Feature 3 — Organise an activity]
|===

== Preconditions

* App is in the Ongoing state with the *organizer* role.

== Steps

. Verify the Ongoing overlay is shown; *Show QR* and *Stop activity* FABs are visible.
. Tap *Stop activity* FAB.
. Observe the transition.

== Expected result

* Ongoing overlay disappears.
* Idle overlay appears.
* Toast message `You are no longer participating in an activity` is shown.
* *Join an activity* FAB is visible.
* *Stop activity* FAB is *not* visible.
* Location updates cease (no further writes to `FakeLocationRepository`).

== UI identifiers

|===
| Element | Selector | Tool

| "Stop activity" FAB
| `contentDescription = "Stop activity"`
| Espresso / Compose

| Toast message
| text = `You are no longer participating in an activity`
| Espresso Toast matcher

| "Join an activity" FAB (appears after)
| text = `Join an activity`
| Espresso / Compose

| "Stop activity" FAB (absent after)
| `contentDescription = "Stop activity"` — assert `doesNotExist()`
| Espresso / Compose
