= UC-07: Start an activity — sign-in prompt for anonymous user

== Preconditions

* App is in the Idle state with an *anonymous* user (not signed in to Google).

== Steps

. Observe the Idle overlay: *Start an activity* FAB is visible.
. Tap *Start an activity* FAB.
. Observe the dialog.
. Tap *Cancel*.

== Expected result

* A dialog appears informing the user that starting an activity requires signing in.
* The dialog offers *Cancel* and *Sign in* choices.
* After tapping "Cancel": dialog dismisses; app remains in the Idle state with no state change.
* No Ongoing overlay is entered.
