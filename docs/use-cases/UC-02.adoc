= UC-02: App launch — location permission denied
:icons: font

[cols="1,3"]
|===
| ID | UC-02
| Path type | Negative
| Feature | xref:../features.adoc#_feature_1_participate_in_an_activity[Feature 1 — Participate in an activity]
|===

== Preconditions

* Location permission is not yet granted on the test device (will be denied during the test).

== Steps

. Launch the application.
. Observe the system permission dialog for `ACCESS_FINE_LOCATION`.
. Tap *Don't allow* / *Deny*.
. Observe the screen after denial.

== Expected result

* The persistent map and Idle controls remain visible.
* A compact notice explains that self-location sharing is off and offers *Enable location*.
* Starting or joining an activity remains possible; group markers and *Track group* remain
  available when the app enters Ongoing state.
* Self-location updates do not start and *Recenter* is absent while permission is denied.
* Granting permission from the notice enables self-location and *Recenter* without replacing the
  native map view or recreating the application shell.
* No crash occurs.
* No location data is written to Firestore.

== Notes

If the system does not re-show the dialog (permission permanently denied), the test setup must reset app permissions via `adb shell pm revoke` or `UiAutomation.grantRuntimePermission()` before the test run.
