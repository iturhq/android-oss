= UC-01: App launch — location permission granted
:icons: font

[cols="1,3"]
|===
| ID | UC-01
| Path type | Positive
| Feature | xref:../features.adoc#_feature_1_participate_in_an_activity[Feature 1 — Participate in an activity]
|===

== Preconditions

* Fresh install *or* location permission not yet granted on the test device.
* Device has GPS capability (or emulator with location simulation enabled).

== Steps

. Launch the application.
. Observe the system permission dialog for `ACCESS_FINE_LOCATION`.
. Tap *Allow* (or equivalent on the API level under test).
. Wait for the map screen to finish loading.

== Expected result

* Map tiles load and the `MapLibreView` is visible.
* Idle overlay is displayed.
* *Join an activity* FAB is visible.
* *Sign in* FAB is visible (anonymous user).
* *Start an activity* FAB is not visible until the user signs in.
* No error message appears.
