== Preconditions

* App is in the Ongoing state with the organiser role.
* The activity has at least one pending `attentionRequests` entry.

== Steps

. Launch or resume the organiser's ongoing activity.
. Observe the organiser controls.
. Inspect the fake repository state.

== Expected result

* The organiser Ongoing overlay renders without error.
* The participant-only *Hail organiser* action is absent.
* Pending attention state is retained in the repository.
* *Show QR* and *Stop activity* remain available.

== Deferred organiser UI

Per canonical `UC-ACTIVITY-005`, organiser-facing presentation is future
work: “Organiser-facing UI or `itur-admin` can surface the request when
implemented.” The older Android draft invented acknowledgement controls
whose selectors were all still marked TBD and for which the repository
contract has no acknowledgement command. That proposal is explicitly
declined in this project; this executable boundary scenario prevents it
from being mistaken for delivered behavior.
