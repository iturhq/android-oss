== Preconditions

* App is in the Ongoing state with the participant role.

== Steps

. Verify *Hail organiser* is visible.
. Tap *Hail organiser* once.
. Observe the ongoing overlay and repository state.

== Expected result

* `requestAttention()` is called exactly once.
* The participant ID is present exactly once in `attentionRequests`.
* The app remains in the Ongoing state.
* No error appears.

== Reconciliation

The canonical `UC-ACTIVITY-005` contract defines a lightweight,
idempotent one-shot attention request. It does not define participant-side
cancellation or acknowledgement state. An older Android draft's toggle and
colour-change proposal is therefore explicitly declined rather than tested
as if it existed.
