= UC-09: Join activity via QR scan — happy path
:icons: font

[cols="1,3"]
|===
| ID | UC-09

| Feature | xref:../features.adoc#_feature_1_participate_in_an_activity[Feature 1 — Participate in an activity]
|===

== Preconditions

* App is in the Idle state (any user — anonymous or registered).
* Camera permission is already granted; denial behavior is covered by UC-10.
* An ongoing activity with ID `AAAABBBBCCCCDDDDEEEE` exists and is joinable.
* A QR code encoding `https://itur.cat/activity/AAAABBBBCCCCDDDDEEEE` is available for scanning.

== Steps

. Tap *Join an activity* FAB.
. Observe the QR Scan bottom sheet appearing.
. Verify the instructions text is visible.
. Present the test QR image to the camera (or inject via `ImageAnalysis` in an instrumented test).
. ML Kit decodes the QR; bottom sheet dismisses automatically.
. Observe the Ongoing overlay.

== Expected result

* Loading indicator appears briefly after QR scan.
* Ongoing overlay appears.
* *Hail organiser* FAB is visible (participant role).
* *Exit activity* FAB is visible.
* *Track group* FAB is visible.
* *Recenter* FAB is visible.
* *Show QR* FAB is *not* visible (not the organiser).
* No error Toast or overlay appears.
