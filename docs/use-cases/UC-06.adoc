== Preconditions

* App is in the Idle state with a registered user.
* Location permission is granted.

== Steps

. Verify *Start an activity* FAB is visible and *Show QR* is absent.
. Tap *Start an activity* FAB.
. Observe the loading indicator.
. Wait for the Ongoing overlay to appear.

== Expected result

* Loading indicator with label `Preparing activity…` is shown briefly.
* Ongoing overlay appears.
* *Show QR* FAB is visible (organizer role).
* *Stop activity* FAB is visible.
* *Track group* FAB is visible.
* *Recenter* FAB is visible.
* *Get help* FAB is visible.
* *Hail organiser* FAB is *not* visible.
* Map location component is active.
